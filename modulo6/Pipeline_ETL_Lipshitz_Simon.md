# Pre-entrega 6: Pipeline ETL con Power Query y M

En este documento se presenta la construcción del pipeline ETL para TechStore en Power BI Desktop a partir del archivo **Pipeline_ETL_Dataset.xlsx**. 
El objetivo fue hacer el perfilado y la limpieza de las cuatro tablas del dataset (clientes, productos, ventas y categorías) en Power Query: 
eliminando duplicados por ID, imputando nulos con criterio técnico, corrigiendo los tipos de datos y aplicando el Merge para enriquecer Fact_Ventas. 
Todo el proceso quedó verificado y documentado en lenguaje M para dejar el modelo limpio y listo para el posterior modelado dimensional y medidas en DAX.
