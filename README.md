⚙️ Guía de Ejecución de Scripts de SQL

Si deseas replicar las consultas y consultar el modelo de datos de este repositorio en tu entorno local, puedes seguir estos pasos:

1. Requisitos: Contar con un entorno de base de datos como MySQL Workbench (o cualquier SGBD compatible).

2. Clonar el repositorio:

git clone https://github.com/tu-usuario/Practicas_coderhouse.git


3. Instrucciones de ejecución:

- Abrir el gestor de base de datos de preferencia (ej. MySQL Workbench) y conectar con la instancia local.

- Abrir y ejecutar los archivos .sql presentes en las carpetas correspondientes respetando el siguiente orden:

  1. Creación de tablas: Ejecutar los scripts de estructura DDL (CREATE TABLE).

  2. Carga de datos: Ejecutar la inserción de registros DML (INSERT INTO o importación de archivos).

  3. Consultas analíticas: Ejecutar los scripts de consulta (SELECT, JOIN, funciones de agregación) para visualizar los resultados de negocio.
